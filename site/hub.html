Semantic Context Index

Method

Research agents read the vendor documentation, release notes, and official blogs. A separate agent checked the high-risk claims and a random sample of cells against primary sources.

Levels

Native GA means the vendor ships the feature and the docs show no preview label. Native preview means the docs show a preview or beta label. Partner or DIY means you need another product or your own code. Not checked means that the research did not find a primary source.

Corrections

Each entry has a source link. If an entry is wrong, open an issue with the correct source at github.com/MKcodeshere/semantic-layer-compare.
